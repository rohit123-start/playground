Image Processing Playground

Sends one or more images to POST /image-processing/process — a direct port of ai-platform's image_analysis.py (a fixed-prompt Qwen Omni vision call; that's genuinely the whole pipeline there for a standalone image, no resize/compress step). Images run concurrently, each with its own Omni latency and token count. An image over Qwen's real per-item size limit (~15 MB) is rejected with a clear error instead of a cryptic provider failure.
