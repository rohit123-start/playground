Embeddings Latency Playground

Sends the same text to both embedding models via POST /embeddings-latency and times each: the current local model (BAAI/bge-small-en-v1.5, via fastembed/ONNX, in-process) vs. the candidate hosted model (qwen/qwen3-embedding-8b, via OpenRouter). Run it a few times — the first call on each side pays a one-time cost (model load locally, cold start on OpenRouter), so look at later runs for the steady-state number.

Semantic Search Test

Embeds one query plus a set of candidate documents with both models, ranks the documents by cosine similarity to the query, and shows each model's ranking side by side — the question that actually matters for retrieval (app/rag/retrieval.py's floors), not just latency. The prefilled case mixes a true backend decision, a correction/update of it, an unrelated decision, an unrelated fact, and an unrelated question that superficially overlaps ("backend" vs. "password") to see whether each model keeps it below the relevant hits.

Ranks are independent per model — compare the order, not just top score
Model Latency Precision@K Perfectly separated?

Precision@K = share of the top K ranked docs that are truly relevant (K = number of ground-truth docs given). Separated = every relevant doc outranked every irrelevant one.
