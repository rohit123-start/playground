Audio Processing Playground

Sends one or more audio files to POST /audio-processing/process — a direct port of ai-platform's audio_processing.py (a fixed-prompt Qwen Omni audio call; no chunking in that codebase — standalone audio is sent whole). Files run concurrently, each with its own Omni latency and token count. Unlike the image section, audio routinely exceeds Qwen's real per-item size limit for audio (~6 MB — lower than video/image's ~15 MB limit, confirmed by live testing) just from running a few minutes long, so an oversized file is automatically re-encoded down to a lower bitrate and retried before being rejected.
